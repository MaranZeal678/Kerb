# Escalation Matrix

## Disputed claims
Refunds must not be issued on a claim in status "disputed". Any refund request on a disputed claim must be routed to a supervisor for resolution of the dispute before any disbursement. The system operator should file a handoff summarizing the request and the dispute status.

## Fraud indicators
Claims flagged for fraud review are frozen for all disbursement actions. Route to the Special Investigations Unit.

## Amount limits
Single refunds over $10,000 require director sign-off in addition to standard large-refund controls.

## Handoff contents
A proper escalation handoff includes: the claim number, the requested action, the blocking condition, and the steps already completed.
