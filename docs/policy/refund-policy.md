# Refund Policy

## 1. Scope
This policy governs all customer refunds issued through the Meridian claims portal by claims operations staff.

## 2. Eligibility
A refund may be issued on any claim in status "open" or "approved" where a balance is due to the customer. Refunds are issued from the claim detail screen using the Start Refund action.

## 3. Standard refunds (up to $500)
For refunds of five hundred dollars ($500.00) or less, the operator enters the refund amount and approves the refund. No additional documentation is required for standard refunds.

## 4. Large refunds (over $500)

### 4.1 Threshold
Any refund exceeding five hundred dollars ($500.00) is classified as a large refund and requires additional controls before approval.

### 4.2 Reason code requirement
Large refunds require a reason code. The operator must select the applicable reason code from the reason code list before approval. Refunds issued to correct a processing error must use reason code RC-07. A large refund submitted without a reason code will be rejected by the system.

### 4.3 Documentation
Supervisors have discretion regarding additional documentation on larger disbursements; a brief written note can be appropriate in some circumstances depending on context and history.

## 5. Approval
After all required fields are complete, the operator approves the refund using the Approve Refund action. Approval finalizes the disbursement and updates the claim status to "refunded".
