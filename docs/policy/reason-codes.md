# Reason Codes

Reason codes classify the cause of a disbursement or adjustment. When a reason code is required by policy, select the single most specific code.

| Code | Meaning |
|---|---|
| RC-01 | Duplicate payment received |
| RC-02 | Overpayment by customer |
| RC-03 | Policy cancellation — pro-rated return |
| RC-04 | Goodwill adjustment (supervisor approval required) |
| RC-05 | Billing system error |
| RC-06 | Fraudulent charge reversal |
| RC-07 | Processing error — refund to correct a claim processed incorrectly |
| RC-08 | Premium recalculation |
| RC-09 | Regulatory remediation |
| RC-10 | Chargeback settlement |
| RC-11 | Class action / bulk remediation |
| RC-12 | Other (memo required) |

Notes: RC-07 is the standard code for refunds correcting a processing error on a claim. RC-12 may only be used when no other code applies and always requires an explanatory memo.
